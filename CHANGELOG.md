# Changelog

## 0.3.0 (unreleased)

- Modular provider SDK with Instagram as the reference provider and explicit plugin loading.
- Generic `sget` command; existing `igd` and `ig-downloader` commands retained.
- Source-independent offline checks and opt-in live resolution workflows.
- Public MIT licensing clarified; upstream notice retained and js-cookie notice included.
- Governance, security, contribution and non-destructive repository-independence procedures.
- CLI tarball and deterministic extension ZIP packaging, checksums, cross-platform install tests.
- Separate CLI and extension release tags; releases are drafts until reviewed, with no npm publication.

Known limitations: live authenticated Instagram downloads and browser runtime acceptance remain unverified. GitHub fork-network metadata has not been detached. Only Instagram is built in.
